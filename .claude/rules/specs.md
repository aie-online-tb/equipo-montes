# Reglas para specs

- Una carpeta por spec: `specs/NNN-nombre-corto/` con `spec.md`, y `plan.md` y `tasks.md` cuando se apruebe.
- `spec.md` dice qué y por qué, nunca cómo. El cómo va en `plan.md`.
- Toda spec termina con criterios de aceptación comprobables.
- No marques una spec como aprobada: eso lo hace una persona.
