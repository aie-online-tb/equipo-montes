# Cierre de semana

Cuándo: viernes. Quién: TA.

## Plantilla para OCT26

En OCT26 el cierre es más guiado que en MAY26: recomendaciones por orden de prioridad, con enlaces, y qué cuenta para el porcentaje de progreso.

```
¡Buenas, mi gente! @canal

Cerramos la semana del Sprint {N}. Os dejo un resumen, lo que viene y qué priorizar.

**📚 Esta semana**
* **LR teórica (jueves):** {idea principal}.
* **Sesión de dudas (lunes):** {si hubo algo destacable del sprint {N-1}}.
* **LR práctica (martes):** {idea principal}.
* **Miércoles:** {taller, Microcredencial UAM o masterclass}. Si no pudisteis venir, tenéis la [grabación en diferido]({ENLACE_GRABACION}).

**📅 La semana que viene**
* {Festivos, cambios de horario, enunciados o entregas.}

**✅ Qué priorizar** (por orden)
1. {Lo imprescindible, con enlace.}
2. {…}
3. {…}

**📈 Qué cuenta para vuestro progreso**
* {Qué elementos del campus entran en el % de progreso esta semana.}

¡Buen fin de semana! 🙌
```

## Reglas

- La prioridad sale de lo que más cuesta a los alumnos esa semana: lo que se vio en la sesión de dudas y lo que dice la hoja de seguimiento.
- Las recomendaciones no son obligatorias, salvo las entregas de TC y PB.
- Pendiente: un cierre real de OCT26 como ejemplo. El de abajo es de MAY26, que usa una versión más corta, sin prioridades ni progreso.

## Ejemplo real (MAY26, viernes 06/11)

```
¡Buenas, mi gente! @canal

Cerramos la semana. Os dejo un resumen de lo trabajado, lo que viene y algunas recomendaciones para el puente.

**📚 Esta semana**
* **Live Reviews**: hemos llevado la API a algo parecido a un servicio real: seguridad (API key, límites de uso, errores bien resueltos) y un agente expuesto detrás de esa API. Idea para quedarse: la API valida, protege y adapta; el agente decide.
* **Masterclass del jueves**: construimos una API con FastAPI y le conectamos un agente básico, con demo en directo y práctica. Si no pudisteis venir, tenéis la grabación en diferido.

**📅 La semana que viene**
* **Lunes 09/11: festivo, no hay clase.**
* **Martes 10/11: continuamos con el sprint actual** con normalidad.
* **Se lanza el proyecto final.** Os pillará con el último sprint aún por ver, así que conviene llegar con todo lo anterior bien asentado.

**🌉 Recomendaciones para el puente** (nada obligatorio, organizaos como os venga mejor)
1. Si os perdisteis alguna sesión, verla en diferido.
2. Repetir por vuestra cuenta la API de la masterclass: probad las rutas desde `/docs` y mirad qué pasa cuando algo falla (clave incorrecta, dato inválido, agente caído). No necesitáis clave de Gemini.
3. Echar un vistazo a la teoría y a los READMEs de la carpeta del sprint en el repo.
4. **Afianzar cualquier parte en la que tengáis dudas.** Con el proyecto final encima, este es el mejor momento para dejar todo claro y listo; si algo se os resiste, escribidnos por aquí.

Disfrutad del puente 🙌
```
