# plugins

Los plugins de Claude Code del equipo. Cada uno se publica en el marketplace del repo (`.claude-plugin/marketplace.json`).

| Plugin | Qué trae |
| --- | --- |
| `aie-equipo` | `normas-aie`, `preparar-sprint`, `liberar-sprint` y `acta-sesion` |

Al empezar hay un solo plugin. Uno nuevo solo se crea si un grupo de skills no tiene sentido para los dos.

No entra aquí: lo que aún no ha revisado la otra persona (va en `incubadora/`).
